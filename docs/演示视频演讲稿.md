# MockMate 演示视频演讲稿

> 时长建议：约 6 分钟
> 分辨率：1080p，MP4，普通话
> 录制环境：Chrome / Edge 无痕窗口，全屏，关闭通知

## 完整流程与逐字稿

| 时间 | 画面操作 | 讲解词 |
|---|---|---|
| 0:00-0:20 | 展示首页标题 | 大家好，我们带来的作品叫 MockMate，一款面向应届生的 AI 智能面试教练。很多同学在求职时最缺的不是能力，而是真实、可反复练习的面试场景。MockMate 就是来解决这个问题的：它根据你的简历和目标岗位，模拟真实面试官进行多轮追问，再给你一份可量化的复盘报告。 |
| 0:20-0:55 | 点击「上传文件」，选择一份 PDF 简历 | 这是我们的首页。你不需要手动打字，直接上传一份 PDF 或 Word 简历，系统会自动把简历文字提取出来。 |
| 0:55-1:30 | 在 JD 框粘贴岗位描述，点击「开始分析」 | 填好目标岗位 JD 后，我们先做一个很有意思的功能：差距分析。点击开始分析，系统会结合简历和岗位，给出匹配度分数、你已经具备的能力、还缺的能力，以及你可能会被问到的高频问题。这样面试之前，你就知道自己该重点准备什么。 |
| 1:30-1:55 | 选择「技术面」，点击「开始模拟面试」 | 接下来选择面试官风格。我们支持技术面、HR 面和压力面。这里我选技术面，开始面试。 |
| 1:55-2:20 | 展示面试官开场 | 大家注意，面试官不是随便问，而是会围绕我刚才填的简历和岗位来追问。 |
| 2:20-3:10 | 输入回答并发送，展示流式输出和追问 | 我来回答第一个问题。大家可以看到，输出是流式的。而且每一轮回答之后，面试官会先评估我的回答，再从题库里选下一题，然后继续追问。这就是我们做的工具调用 Agent，面试节奏更接近真实。 |
| 3:10-3:45 | 点「语音」说话；点面试官消息旁的「朗读」 | 除了打字，你还可以直接用语音回答，面试官的提问也能朗读出来。这样面试更像一场真实对话。 |
| 3:45-4:25 | 点击「结束并生成复盘报告」 | 面试几轮之后，点击结束并生成复盘报告。系统会给出总分，还有技术能力、项目经验、表达逻辑、岗位匹配、综合素质五个维度的雷达图，以及亮点、待改进和改进建议。 |
| 4:25-4:50 | 滚动到成长曲线 | 每次复盘的成绩都会被保存下来，形成你的能力成长曲线。经过几次训练，你能直观看到自己有没有进步。 |
| 4:50-5:25 | 切到架构图或代码页 | 简单说一下技术亮点：我们用了向量检索增强，让面试官围绕你的简历和岗位追问；用工具调用 Agent 显式化面试决策；还有文档解析、图片 OCR、语音输入输出这些多模态能力；同时也做了内容安全过滤，比如手机号脱敏、违规内容拦截。 |
| 5:25-5:55 | 回到首页 | MockMate 把求职准备从模糊的感受，变成了可量化、可迭代的训练闭环。谢谢大家。 |

## 录制前准备

- 提前准备一份测试用 PDF 简历和一段前端 JD，内容与演示一致。
- 提前跑通一遍全流程，确认在线地址可用、截图和语音正常。
- 手机调静音，关闭无关窗口和通知。

## 录制技巧

- 语速平稳，每句话之间留半秒停顿，方便评委听清。
- 操作和讲解同步，讲解先于点击约半秒。
- 如果语音识别第一次没反应，就正常演示并口播说明即可，不要中断重录整段。
