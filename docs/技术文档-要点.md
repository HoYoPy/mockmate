# MockMate · 技术文档要点（可直接用于 ≤30 页 PDF）

## 1. 项目概述

MockMate 是一款面向应届生的 AI 智能面试教练。候选人上传简历和目标岗位 JD，选择面试官风格（技术面 / HR 面 / 压力面），系统通过「向量检索增强 + 工具调用 Agent」进行多轮追问，最终输出多维度评分、能力雷达图与结构化复盘报告。面试前还提供「简历 × 岗位差距分析」，帮助用户看清匹配度、缺口技能和可能被问到的问题。

## 2. 社会价值

- 应届生普遍缺少真实面试训练场景，面试焦虑高、试错成本大，MockMate 提供低成本、可反复练习的模拟面试环境。
- 通过差距分析和复盘报告，把“求职准备”从模糊感受变成可量化的能力反馈，促进就业公平，尤其是普通院校学生的求职竞争力提升。
- 多面试官人格 + 压力面，帮助用户提前适应不同面试场景，缓解临场紧张。

## 3. 商业模式

- **B2C 订阅**：免费体验若干次面试后，付费解锁不限次模拟、完整复盘、成长曲线和岗位题库。
- **B2B 高校就业指导**：面向高校就业中心提供批量账号、就业数据看板和定制化题库，用于就业指导课程。
- **B2B2C 招聘平台合作**：作为招聘平台的求职辅导模块，向用户提供针对性面试训练。

## 4. 市场空间

- 2026 届全国普通高校毕业生规模预计超过 1200 万，求职培训是高频刚需。
- 应届生求职服务市场持续增长，AI 面试训练、简历优化、模拟面试是增长最快的细分方向之一。
- 目标用户基数大、使用频次集中在秋招/春招，具备明确的付费节点和传播场景。

## 6. AI 选型理由（可直接引用）

- **RAG 向量检索**：先做字符 n-gram TF-IDF 向量 + 关键词重排，保证离线、免费、serverless 稳定；预留 bge-small-zh-v1.5 语义 embedding 接口，可在浏览器端做端侧推理。
- **工具调用 Agent**：用 `evaluate_answer / pick_next_question / finish_interview` 把面试流程显式化，避免纯 prompt 的不可控性。
- **结构化输出**：复盘和差距分析优先使用 `response_format: json_object`，失败自动降级重试，保证报告格式稳定。
- **多模型降级**：主模型失败自动切换备选模型，提升服务可用性。
