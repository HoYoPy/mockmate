## 1. 项目概述

MockMate 是一款面向应届生的 AI 智能面试训练与复盘工具。候选人上传简历和目标岗位 JD，选择面试官风格（技术面 / HR 面 / 压力面），系统通过「向量检索增强（RAG）+ 工具调用 Agent」进行多轮追问，最终输出多维度评分、能力雷达图与结构化复盘报告。面试前还提供「简历 × 岗位差距分析」，帮助用户看清匹配度、缺口技能和可能被问到的问题。

**要解决的问题**：应届生缺少真实面试训练机会，不知道面试官会问什么、自己的回答差在哪、如何针对性提升。

**核心方案**：把面试过程拆解为可量化的能力评估，用 AI 模拟真实面试官的多轮追问，并生成结构化反馈。

## 2. 需求分析

### 2.1 目标用户

- 准备求职的应届毕业生
- 希望提升面试表达和临场能力的学生
- 高校就业指导老师

### 2.2 核心需求

| 需求 | 说明 |
|---|---|
| 个性化模拟面试 | 根据简历和岗位 JD 生成贴合的追问 |
| 多场景面试 | 技术面、HR 面、压力面 |
| 能力反馈 | 多维度评分、能力雷达图、亮点与待改进 |
| 求职准备 | 面试前识别能力缺口和可能被问到的问题 |
| 持续进步 | 记录历史成绩并展示成长曲线 |

- 页面需移动端适配，关键操作需有加载态和错误兜底

## 3. 系统架构设计

```text
浏览器（Next.js 前端）
   │  简历 / JD / 语音 / 面试回答
   ▼
Next.js App Router
   ├── POST /api/chat            对话（Agent + RAG）
   ├── POST /api/report          结构化复盘报告
   ├── POST /api/gap-analysis    简历 × 岗位差距分析
   └── POST /api/parse-resume    简历文件解析
   ▼
服务端逻辑层
   ├── 向量检索（RAG）：question-bank.json + TF-IDF 余弦相似度
   ├── 工具调用 Agent：evaluate_answer / pick_next_question / finish_interview
   ├── 内容安全：敏感信息脱敏 + 违规拦截
   └── 模型降级：主模型失败自动切换备选
   ▼
OpenAI 兼容大模型接口（DeepSeek / 智谱 / OpenAI 等）
```

## 4. AI 技术方案

### 4.1 向量检索增强（RAG）

**题库构建**：`data/question-bank.json` 结构化存储面试题，字段包括 `category / persona / skills / difficulty / keywords / question / points`，覆盖技术、项目、行为、压力、职业规划等类别。

**检索流程**：

1. 对简历和岗位 JD 进行字符 n-gram 分词。
2. 对题库建立 TF-IDF 向量空间。
3. 计算查询向量与题目向量的余弦相似度。
4. 结合关键词命中、面试官风格做加权重排。
5. 将检索到的题目与「考察点」注入系统提示词，指导面试官围绕考察点追问。

**设计取舍**：先使用离线、免费、serverless 友好的字符 n-gram TF-IDF 向量，避免在服务端运行时加载大模型；模块已抽象，后续可在浏览器端用 `bge-small-zh-v1.5` 做语义 embedding，实现端侧 AI。

### 4.2 工具调用 Agent

面试官不再只是一段静态提示词，而是通过工具调用显式化面试决策：

| 工具 | 作用 |
|---|---|
| `evaluate_answer` | 评估上一轮回答的深度、数据支撑和是否跑题 |
| `pick_next_question` | 从题库按技能维度选下一题 |
| `finish_interview` | 覆盖足够维度后收尾 |

服务端以最多 4 步的循环执行：模型返回 `tool_calls` → 执行工具 → 将结果作为 `tool` 消息回填 → 模型继续，直到输出纯文本。工具调用失败时自动回退到普通流式对话，保证服务不中断。

### 4.3 多模态输入与语音

- 简历文件上传：`.txt / .md / .docx / .pdf`
- JD 截图 OCR：浏览器端 tesseract.js 中文识别，无需视觉大模型
- 语音输入：Web Speech API 将语音转为文字
- 语音朗读：SpeechSynthesis 选择自然中文音色

### 4.4 内容安全

`lib/ai/guard.ts` 实现：

- 敏感信息脱敏：手机号、邮箱、身份证、API Key、银行卡号
- 违规内容拦截：色情、暴力、自残、违法类关键词
- 不友好用语过滤：将辱骂词替换为 `[不友好用语]`

安全策略同时应用于用户输入和模型输出。

### 4.5 输出稳定性与可靠性

- 复盘报告与差距分析优先使用 `response_format: json_object` 强约束输出
- JSON 解析失败或服务不支持时，自动去掉约束重试一次
- 主模型失败时，按 `OPENAI_FALLBACKS` 配置自动切换备用模型
- 对话输出改为标准 SSE 流式，限制单次 3000 字，并设置 30 秒超时

## 5. 核心功能实现

### 5.1 模拟面试流程

1. 选择面试官风格，填写简历与岗位 JD。
2. 开始面试：系统检索相关题目并注入提示词，Agent 输出开场。
3. 多轮追问：模型评估回答、选题、追问。
4. 结束面试：生成结构化复盘报告。

### 5.2 结构化复盘报告

报告包含：

- 总分（0-100）
- 五维评分：技术能力、项目经验、表达逻辑、岗位匹配、综合素质
- 亮点、待改进、改进建议
- 能力雷达图

### 5.3 简历 × 岗位差距分析

面试前分析简历与 JD 的匹配度，输出：

- 匹配度分数
- 已匹配能力
- 缺口技能
- 可能被问到的问题（由 RAG 检索）
- 提升建议

### 5.4 能力成长曲线

每次复盘结果写入 `localStorage`，在报告底部用折线图展示历史成绩变化。

## 7. 创新点说明

### 7.1 技术应用创新

- 用工具调用 Agent 显式化「评估 → 选题 → 追问 → 收尾」面试决策链，比纯 Prompt 更可控
- RAG 检索结果携带「考察点」，让追问有据可依

### 7.2 场景创新

- 面试前先做「简历 × 岗位差距分析」，把求职准备从模糊感受变成可量化的能力反馈

### 7.3 产品创新

- 多面试官人格（技术 / HR / 压力面）+ 结构化复盘 + 成长曲线，形成完整训练闭环

### 7.4 交互创新

- 流式输出 + 分阶段思考状态（理解回答 / 选题 / 组织语言）
- 语音输入 + 面试官语音朗读的语音闭环
- 能力雷达图与成长曲线可视化

## 8. 社会价值与商业分析

### 8.1 社会价值

- 应届生缺少真实面试训练场景，MockMate 提供低成本、可反复练习的模拟面试环境
- 通过差距分析和复盘报告，把求职准备变成可量化的能力反馈，促进就业公平
- 压力面帮助用户提前适应不同面试场景，缓解临场紧张

### 8.2 商业模式

- B2C 订阅：免费体验后付费解锁不限次模拟和完整复盘
- B2B 高校就业指导：面向高校就业中心提供批量账号与就业数据看板
- B2B2C 招聘平台合作：作为招聘平台的求职辅导模块

### 8.3 市场空间

- 2026 届全国高校毕业生规模预计超过 1200 万，求职培训是高频刚需
- AI 面试训练、简历优化、模拟面试是求职服务市场增长最快的细分方向之一
