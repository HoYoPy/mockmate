# 演示视频脚本（5-8 分钟，1080p，普通话）

## 建议总时长：约 6 分钟

| 时间 | 内容 | 画面 |
|---|---|---|
| 0:00-0:20 | 开场：介绍作品名称、目标用户、解决的问题 | 首页标题 + 项目 Logo |
| 0:20-1:00 | 填写简历和岗位 JD，展示文件上传解析 | 上传 PDF 简历，自动填入文本 |
| 1:00-1:30 | 展示「简历 × 岗位差距分析」 | 匹配度、缺口技能、可能被问到的问题 |
| 1:30-2:00 | 选择面试官风格，开始模拟面试 | 技术面开场提问 |
| 2:00-3:30 | 多轮问答，展示流式输出和追问策略 | 回答 → 面试官追问，强调 AI 亮点 |
| 3:30-4:00 | 展示语音输入和面试官语音朗读 | 点语音按钮说话，点朗读播放 |
| 4:00-4:40 | 结束面试，生成复盘报告 | 总分、雷达图、亮点/待改进/建议 |
| 4:40-5:10 | 展示能力成长曲线 | 第二次面试后折线图 |
| 5:10-5:50 | 技术亮点讲解：RAG + Agent + 多模态 + 内容安全 | 切到代码/架构图，快速说明 |
| 5:50-6:00 | 总结：社会价值与展望 | 回到首页 + 结束语 |

## 讲解要点

1. 开头一句话定位：**“MockMate 是一款面向应届生的 AI 智能面试教练。”**
2. 每个功能演示时，先一句话说清“用户得到什么”，再操作。
3. AI 亮点重点说：
   - 向量检索：面试官会围绕你的简历和岗位追问
   - Agent：面试官会先评估回答、再从题库选题、再追问
   - 多模态：能传 PDF 简历、识别 JD 截图、语音输入和朗读
   - 内容安全：敏感信息脱敏、违规内容拦截
4. 复盘报告部分突出“可量化的能力反馈”。
5. 结尾一句：**“它把求职准备从模糊感受，变成了可量化、可迭代的训练闭环。”**

## 录制建议

- 用 Chrome 或 Edge，打开无痕窗口避免插件干扰
- 分辨率 1920×1080，全屏录制
- 关闭无关通知，语速平稳
- 如果 TTS 音色第一次不自然，刷新页面等音色加载后再点朗读
